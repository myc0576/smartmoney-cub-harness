# SmartMoney-Cub Editorial System

Reusable design system for SmartMoney-Cub public visuals (README cover, system flow, docs artwork).

## Understanding of the brand

SmartMoney-Cub (`smartmoney-cub-harness`) is a local-first, **read-only** trading review and evidence-governance control plane. It never places, cancels, or executes trades. Its personality is a calm research workbench: evidence over prediction, human judgment over automation, plain portable text over private databases.

The visual language is an original "Claude-inspired editorial" direction — warm paper surfaces, humanist serif display type, one restrained terracotta accent, hairline connectors, generous whitespace. It deliberately avoids finance-software cliches and any Anthropic/Claude brand assets.
