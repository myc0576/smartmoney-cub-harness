# Cover Design

Canonical cover assets:

- `assets/smartmoney-cub-harness-cover.svg`
- `assets/smartmoney-cub-harness-cover.png`

## Requirements

- Ratio: 1280x640 GitHub social preview.
- Mood: warm, calm, structured, human.
- Title: `smartmoney-cub` / `harness`.
- Chinese line: `聪明资金幼年体：陪你复盘，不替你下单`
- English subtitle: `Local-first AI review loop for subjective traders`
- Badges: `READ-ONLY`, `LOCAL-FIRST`, `D1/D3 REVIEW`
- Flow: `Plan -> Record -> Review -> Memory -> Evolve`
- Footer: `No orders · No broker execution · No telemetry`

## Typography

Use system font fallback:

```text
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans SC", "Microsoft YaHei", "PingFang SC", Arial, sans-serif
```

Minimum sizes:

- Main title: at least 56px.
- Subtitle: at least 24px.
- Badge text: at least 18px.
- Smallest text: at least 16px.

## Export

Export PNG from SVG with CairoSVG or an equivalent local renderer. Check that Chinese text renders as real glyphs, not placeholder squares or dots.
