the attribution, NOTICE, patent grant, and modification notice obligations in

The Apache-2.0 code license does not automatically grant permission to use the
`smartmoney-cub-harness` project name, logo, cover image, or other brand assets
for misleading promotion or confusing redistribution.

## Allowed Uses

- Normal references to the project name when describing compatibility,
  provenance, reviews, or citations.
- Fork attribution that clearly identifies the fork as a fork.
- Non-confusing statements such as "based on smartmoney-cub-harness" or
  "compatible with smartmoney-cub-harness artifacts."

## Not Allowed

- Claiming that a fork, modified distribution, service, package, or integration
  is the official project when it is not.
- Using a similar project name, logo, cover image, or brand story in a way that
  misleads users about origin, maintenance, or endorsement.
- Suggesting official endorsement, partnership, or certification without written
  permission.

These trademark and brand-use boundaries do not limit the Apache-2.0 license
for the repository code. They only clarify how project identity should be used
without confusing users.
